# 停留规则领域指南（算法口径 · 参考规则速查 · 护栏）

## 一、核心概念：x / N / y 三元组

| 符号 | 含义 | 例（申根） |
|---|---|---|
| **x** `stay_single` | 单次入境最长停留天数 | 90 天 |
| **N** `stay_window` | 累计统计窗口（天） | 180 天 |
| **y** `stay_window_max` | 窗口内累计停留上限 | 90 天 |

- **滚动窗口**（默认）：窗口 = 「从今天往回数 N 天，含今天」。每天的额度占用会逐日滑出窗口。
- **自然年窗口**（少数国家，如墨西哥）：每年目的地时区 1 月 1 日清零重算。
- **无窗口国家**（N/y 为 0）：只看单次上限，离境后重新入境一般重新计算（但注意入境章口径）。

## 二、三条关键算法口径（向用户解释时的依据）

1. **天数含入境当日**：9-01 入境、9-20 离境 = 停留 20 天（离境日计入）。这是边检「从入境章当天起算」的通用口径。
2. **滚动窗口逐日回补**：额度不是一次性恢复——最早占用日滑出窗口那天起，每天恢复 1 天。
   误解为「整段 M 天一次性回来」会导致用户提前入境而超停。
3. **同池共享额度，跳国不清零**：申根 35 国（含瑞士/挪威/冰岛及摩纳哥等微型国）共用一个
   90/180 池。从法国跳到德国**不重置**额度。美国（含关岛/波多黎各等）、英国（含皇家属地）同理合并天数。

## 四、护栏哲学（本 Skill 的差异化，必须遵守）

1. **未收录 ≠ 猜数字**：没有官方依据的规则数字，绝不编造。宁可问用户「你签证页/入境章上
   写的允许停留多少天？」——用户手里的官方数字比记忆可靠。
2. **来源分级如实展示**：内置速查 = 「参考值·待核验」；用户提供的签证页数字 = 「按你的
   签证口径」；申根 90/180 = 唯一内置已确认值。
3. **执法口径双示**（有依据时）：纸面规则与落地实践可能不同（如泰国）。给用户决策依据，
   不替用户拍板。
4. **免责声明**：每次输出计算结果必须附带「本计算仅供参考，不构成法律建议；请以边检
   入境章与使领馆官方信息为准」。
